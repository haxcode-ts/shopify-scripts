# Shopify Scripts

A collection of useful Shopify scripts, snippets, customizations, and
storefront tricks built to improve the look, functionality, and user
experience of Shopify stores.

## What's inside

This repository contains lightweight, reusable solutions for Shopify
themes, including visual effects, UI enhancements, automation snippets,
and other storefront improvements.

Each script may include its own folder, installation guide,
configuration options, and usage notes.

## How to use

1.  Browse the repository and choose a script.
2.  Open its folder and read the included instructions.
3.  Back up or duplicate your Shopify theme before making changes.
4.  Follow the script's installation steps and adjust its settings if
    needed.
5.  Test on desktop and mobile before publishing.

**Note:** Shopify themes differ. Some scripts may need adjustments to
work with your theme or other installed apps. Always test changes on a
duplicate theme first.

## Contributing

Have an improvement or a useful Shopify trick? Add it as a separate,
